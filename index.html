SDG16 Intelligence Platform

Explainable ML + RAG platform for forecasting and interpreting Vietnam's SDG16 score (Peace, Justice, and Strong Institutions) — a production-oriented implementation of a research framework for diagnosing governance gaps and forecasting score trajectories toward 2030.

  • End-to-end pipeline: SDSN data → Data Lake → PySpark/Spark MLlib → Explainability → RAG (Qdrant) → LLM → FastAPI → Spring Boot → Vue
  • Processes a panel of 4,392 country-year observations across 183 countries (2000–2023) with 17 SDG16 sub-indicators, using time-based train/validation/test splits to prevent leakage
  • Explainability layer breaks down Vietnam's governance gaps by indicator; microservice architecture cleanly separates data/ML, backend, and frontend layers for parallel team work
